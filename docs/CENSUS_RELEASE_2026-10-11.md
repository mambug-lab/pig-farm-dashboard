# J열 종업 실사와 다음 날 재고 승계

## 운영 규칙

- 농장 작업자는 기존 돈사·돈방 행의 J열에 이동 작업을 모두 마친 뒤의 최종 실사두수를 숫자로 입력합니다. 0두는 유효한 실사, 빈칸은 미실사입니다. 입력 열·행·서식은 늘리지 않습니다.
- 해당 일의 확정 마감두수는 J이며 다음 날 D열 기초두수로 이어집니다. 당일 I열 계산식과 E:H의 이동·폐사·출하 원기록은 유지합니다. 같은 실사를 다음 날 다시 기입할 필요가 없습니다.
- E:H의 0과 빈칸은 모두 변동 없음입니다. 마지막 실제 변동·실사일까지 기존 날짜 블록을 모두 집계하며, 이후의 빈 날짜나 0만 적힌 날짜는 집계 종료일을 늘리지 않습니다. 특정 앵커 행뿐 아니라 모든 돈방의 변동을 확인합니다.
- 월·연도 경계와 수기 월초 재고가 기존 J의 효력을 끊지 않습니다. J를 삭제하면 보호된 수기 기초값이 복원되며 삭제 관측 이력은 남습니다.
- 실사차이를 폐사·출하·전입·전출로 간주하지 않습니다. 누락 원기록을 정정하면 실사조정 차이를 다시 계산합니다.
- 과거 관리사무소 공식 재고와 돈방 합계 사이에 미배분 차이가 남아 있는 경우, 일부 돈방의 J만으로 차이를 임의로 배분하거나 제거하지 않습니다. 해당 돈군의 나머지 돈방을 순차 실사해 모두 확인하면 상세 합계로 공식 재고를 확정합니다.
- 같은 날 돈군 전체 J와 별도 그룹 실사가 충돌하면 새 연동 출력을 중단하여 어느 한쪽을 임의로 채택하지 않습니다.

## 화면과 저장 위치

메인 화면의 기존 마크업과 스타일을 유지했습니다. `돈사별 상세 보기 → 실사 · MSY 확인`에서 돈군을 선택하면 공식/상세 두수, 최근 J열 실사일, 미실사 돈방, 미해결 잔차 및 원인 미확인 조정을 확인할 수 있습니다. 기존 돈사별 두수 화면도 유지합니다. 한국어·러시아어를 지원합니다.

숨김 시스템 시트는 작업자의 추가 입력을 요구하지 않습니다.

| 시트 | 역할 |
|---|---|
| 대시보드_실사검증용 | 메인 메타와 대조하는 세부 조회 전용 A:C 보고서 |
| 시스템_실사이력 | J값·조정 결과의 최초 관측/수정/삭제 이력 |
| 시스템_실사수식원본 | 교체 전 D값·수식과 교체 수식 백업 |
| 시스템_실사이월확인 | 첫 실사 이전의 수기 이월 불일치 등 확인 대상 |

이력의 시각은 시스템이 변경을 관측한 시각입니다. 실제 입력 시각이나 입력자를 복원한 것으로 해석하지 않습니다. 갱신 사이에 여러 번 변경되면 중간 상태까지 보장하지 않습니다.

## MSY

분만·임신 여부와 관계없이 모돈군 전체의 일별 기초 두수를 합산한 모돈일수로 `누적 출하 × 365 / 모돈일수`를 계산합니다. 불임·재발정 등 비생산 상태의 모돈도 모돈군에 있는 동안 포함합니다. 마감 J는 다음 날 기초 모돈수에 반영합니다.

집계 기간 안에서 E:H의 0과 빈칸은 동일한 무변동일이며 누락이나 신뢰도 저하 사유로 삼지 않습니다. 날짜 블록 자체가 없는 경우에만 모돈수를 추정 이월하고 누락으로 표시합니다. 모돈 잔차·모돈 실사조정 원인 미확인도 `잠정` 사유입니다. `기록 요건 충족`은 실제 출하전표와 모든 실사의 대조 완료를 뜻하지 않습니다. 이 계산은 운영 기간의 연환산 지표이며 6개월 전 모돈수 등을 쓰는 외부 통계와 비교하려면 기간·모돈 범위·출하 범위를 맞춰야 합니다.

실제 운영 수치와 누락일 목록은 권한이 있는 운영 기록 및 대시보드에서 확인합니다.

## 검증

- Node 내장 테스트: 당일 이동 후 J, 다음 날 승계, 월·연도 경계, J의 0/빈칸/잘못된 값, 부분 실사와 그룹 잔차, 원기록 사후 정정, 수정·삭제 이력, 수기값 보호/복구, HTML 메타 일치/오류 격리, 한국어·러시아어. 추가로 이동 0/빈칸의 계산·종료일 동등성, 무변동 월말 승계와 비임신 모돈 포함을 검증합니다.
- 실제 Google 검증 사본에서 월말 J의 다음 달 기초 승계와 이후 이동 반영을 확인했습니다. 출하·폐사와 모돈 MSY가 분리되는지도 검증했습니다.
- 시험 J 삭제 후 기존 수기값과 공식 합계로 복구됐고 `removed` 이력이 남았습니다.
- 복구 후 원본 셀 대조: D열을 제외한 입력 값·수식과 모든 I열 계산 결과가 일치했습니다.
- 메인 화면 마크업과 기존 인라인 스타일 동일. 로컬 브라우저에서 선택 탭과 실사 상세 표시 확인.
- 정적 테스트는 `node --test tests/*.test.cjs`로 실행합니다. 실제 자료/스크린샷/소스 백업은 공개 저장소에서 제외한 `.local-verification/`에 보관합니다.

## 반영·복구

운영 백업·시험 사본의 식별자와 상세 수치는 비공개 운영 인계 기록에 보관합니다.

원본 스크립트 25개를 변경 직전 재대조했습니다. 기존 갱신 트리거를 유지하며, 신규 입력란이나 트리거를 추가하지 않습니다. 쓰기 갱신 시 안전한 D열 수식을 설치하고 다시 분석합니다. 진단용 읽기 경로는 수식을 설치하거나 상태·이력을 쓰지 않습니다.

되돌리기는 기존 소스만 복원하는 것으로 끝내면 안 됩니다. 반영 전 백업 또는 `시스템_실사수식원본`의 최초 원본을 대조해 D열까지 복구하고 재계산해야 합니다. 이후 농장 입력은 보존해야 하므로 운영 시트 전체를 덮어쓰지 않습니다.

일반 배포 상태는 PROJECT_STATUS.md에, 상세 운영 검증 결과는 비공개 인계 기록에 보관합니다.
